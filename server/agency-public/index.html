System 04 Hybrid Decision Architecture (System 1 + System 2 Orchestration)
33ms Invariant Latency

Deterministic Intent Triage & Generative Routing

Non-Autoregressive Classifier (Laya) + Dynamic Fallback Gateways

Standard industry workflows route simple operational decisions through multi-billion-parameter LLMs, incurring 1.5–3.0s latency, unpredictable schema formatting, and hallucination risks. My architecture introduces Laya—a non-autoregressive encoder decision model—as the deterministic System 1 layer before delegating to generative models.

Laya Decision Engine ModernBERT / mmBERT 33ms Single Forward Pass Zero Generative Hallucination Typed Choice Constraints Gemini / Claude Fallback
  • System 1 (Deterministic Triage): Laya classifies input intent into typed choices (choice, score, noul) within ~33ms on CPU/edge without generating tokens—mathematically eliminating text hallucination.
  • System 2 (Deep Synthesis): Only when high-dimensional extraction or complex reasoning is required does the engine dispatch to Gemini or Claude via resilient rate-limited gateways.
  • Production Economics: Filters out routine classification volume before touching LLM endpoints, slashing API overhead and delivering instantaneous workflow reactions.
